# Copilot Instructions

1. Copy the `copilot-instructions.md` file to `<project>/.github` folder.
```bash
mkdir -p <project>/.github
cp copilot-instructions.md <project>/.github/
```
2. Open the `copilot-instructions.md` file and edit the instructions as needed for your project.

3. Commit and push the changes to your repository.

4. When you start a new chat session with GitHub Copilot Chat, it will automatically load the instructions from the `copilot-instructions.md` file and use them to guide the conversation.

5. Install Caveman Skill. https://github.com/JuliusBrussee/caveman
